# Spēles paskaidrojums
Where Is My Car ir 2D Unity spēle kur vajag savilkt visas mašīnas kopā ar to siluētu. Tā ir veidota Unity mācības iemeslam.

# Kontroles
* Turot peles kreiso pogu var vilkt mašīnu, un atlaidot to var nomest. 
* Z un X groza peēdējo izvēlēto mašīnu pa labi un pa kreisi.
* Ar bultiņu pogām var mainīt pēdējās izvēlētās mašīnas izmēru.
* Ar space var apgriezt mašīnu horizontāli.
