# Spēles paskaidrojums
Where Is My Car ir 2D Unity spēle kur vajag savilkt visas mašīnas kopā ar to siluētu. Tā ir veidota Unity mācības iemeslam. Spēles laikā no labās un kreisās ekrāna puses lido mākoņi, lidmašīnas un bombas, kurām pieskāroties turot mašīnu tā mašīna tiek iznīcināta. Bombām arī var pieskarties vienkārši ar peli un iznīcīnāt tuvākos mākoņus un lidmašīnas. Mašīnas sākumā tiek nejauši apgrieztas lai nogrūtinātu savilkšanas procesu, un tās manuāli vajag apgriezt pareizā veidā.

# Kontroles
* Turot peles kreiso pogu var vilkt mašīnu, un atlaidot to var nomest. 
* Z un X groza peēdējo izvēlēto mašīnu pa labi un pa kreisi.
* Ar bultiņu pogām var mainīt pēdējās izvēlētās mašīnas izmēru.
* Ar space var apgriezt mašīnu horizontāli.
